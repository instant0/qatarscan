# Behavioral rules

- Never delete, move, or rename files without asking.
- Never run git commands unless the user explicitly asks you to.

## Questions vs. directives

A **true question** asks for information, explanation, or reasoning — respond
with text only, do not run any tool. Examples:

> "Why did the build fail?"
> "How does the cache work?"
> "Is it possible to wire this into the config?"

A **directive** asks you to perform an action, even if phrased with "can you",
"could you", or "would you mind" — proceed with tools as needed. Examples:

> "Can you edit this file for me?"
> "Could you run the tests?"
> "Would you mind updating the README?"

If unsure, ask: "Is this a question I should answer, or a task you want done?"
